# 📊 Sales Analysis Project

## 📌 Project Overview

This project focuses on analyzing sales data to identify business trends, understand customer purchasing behavior, and evaluate product and regional sales performance.

An interactive Sales Analysis Dashboard is developed using Python, Streamlit, Pandas, and Plotly to present meaningful business insights through visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products.
- Understand regional sales distribution.
- Analyze customer purchasing patterns.
- Clean and preprocess raw sales data.
- Build an interactive business dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- MySQL
- Streamlit
- Plotly
- CSV Dataset
- VS Code
- Git & GitHub

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/indhutechie29-maker/sales-analysis-project.git
```

### Step 2: Open Project Folder

```bash
cd sales-analysis-project
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Dashboard

```bash
streamlit run app.py
```

### Step 5: Open in Browser

```text
http://localhost:8501
```
