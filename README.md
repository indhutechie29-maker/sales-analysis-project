# Sales Analysis Project

## 📊 Project Overview

This project focuses on analyzing sales and customer data using **Python/Pandas** and **MySQL**.

The project follows an end-to-end data analysis workflow:

**Raw Data → Data Cleaning → MySQL → SQL Analysis → Business Insights**

The main goal is to clean the raw data, store the cleaned data in MySQL, and use SQL queries to identify useful sales patterns across products, regions, and customers.

---

## 🎯 Project Objectives

- Clean raw sales and customer data
- Handle missing/null values
- Remove duplicate records
- Standardize region values
- Load cleaned datasets into MySQL
- Combine sales and customer data using SQL JOINs
- Analyse orders, quantities, products, regions, and customers
- Generate meaningful business insights
